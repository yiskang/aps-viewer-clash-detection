I would not approve the revised specification yet. The v4 findings were addressed, but the revision introduces or exposes four blockers and one smaller gap.

1. **[P1] `bvhcast` does not enumerate only intersecting triangle pairs.**  
   The design assumes every `intersectsTriangles` callback represents a geometric intersection ([spec:425](/Users/kangea/Documents/Workspace/Codes/aps-viewer-clash-detection/docs/superpowers/specs/2026-08-06-collision-library-milestone1-design.md:425)). In reality, the callback receives triangle pairs from overlapping BVH leaves; the callback itself must report whether they intersect. The algorithm must first call and check `triA.intersectsTriangle(triB)`. For coplanar candidates, call it without `targetLine` to avoid the warning. Otherwise a non-intersecting pair can leave `targetLine` invalid or stale and produce a false crossing. [Upstream `bvhcast` contract](https://github.com/gkjohnson/three-mesh-bvh/blob/master/API.md#bvhcast).

2. **[P1] Four vertex samples do not make manifold containment exact.**  
   The proof says one *conclusive* sample is sufficient, but the algorithm does not guarantee finding one ([spec:522](/Users/kangea/Documents/Workspace/Codes/aps-viewer-clash-detection/docs/superpowers/specs/2026-08-06-collision-library-milestone1-design.md:522), [spec:541](/Users/kangea/Documents/Workspace/Codes/aps-viewer-clash-detection/docs/superpowers/specs/2026-08-06-collision-library-milestone1-design.md:541)). Consider a closed solid contained deeply inside a room while sharing one coplanar face with it. There is no proper crossing, and an allowed selection of four source vertices can place every sample on the shared boundary. The query then returns no clash—albeit diagnosed—even though the overlap is much deeper than `minPenetrationDepth`, contradicting the exactness claim at line 584. Continue until a conclusive representative is found, construct a guaranteed interior witness, or weaken the guarantee and add this regression fixture.

3. **[P1] The tolerance frame is still inconsistent under non-uniform transforms.**  
   Tolerances are declared in A’s local classification frame ([spec:349](/Users/kangea/Documents/Workspace/Codes/aps-viewer-clash-detection/docs/superpowers/specs/2026-08-06-collision-library-milestone1-design.md:349)), while `classifyPoint` performs proximity and ray operations in the target BVH’s local frame ([spec:495](/Users/kangea/Documents/Workspace/Codes/aps-viewer-clash-detection/docs/superpowers/specs/2026-08-06-collision-library-milestone1-design.md:495)). When the target is B, `surfaceEpsilon` and `mergeDistance` therefore cannot be compared directly to B-local distances. Under anisotropic scaling there is no direction-independent scalar conversion, and `min(diagonal(A), diagonal(B→A))` is not symmetric when A and B are swapped. Upstream confirms direct BVH queries use BVH-local arguments and results. [MeshBVH API](https://github.com/gkjohnson/three-mesh-bvh/blob/master/API.md#meshbvh). Define a common metric or target-local tolerances with conservative transform bounds, and test swapped operands under anisotropic scale.

4. **[P1] The pinned `three-mesh-bvh` version is not published.**  
   The spec pins `0.9.14` and says it was registry-verified ([spec:220](/Users/kangea/Documents/Workspace/Codes/aps-viewer-clash-detection/docs/superpowers/specs/2026-08-06-collision-library-milestone1-design.md:220)), but npm currently lists `0.9.13` as the latest published version. An exact `0.9.14` dependency will fail installation. Pin an existing version and revalidate the API/source claims against that exact tag. [Official npm package](https://www.npmjs.com/package/three-mesh-bvh).

5. **[P2] Interleaved-position normalization remains underspecified.**  
   The fallback identifies only `attributes.position.data.array` ([spec:270](/Users/kangea/Documents/Workspace/Codes/aps-viewer-clash-detection/docs/superpowers/specs/2026-08-06-collision-library-milestone1-design.md:270)), without explicitly mapping `position.data.stride` and `position.offset` into `positionStride` and `positionOffset`. Specify those mappings and make the fixture use a stride greater than three with a nonzero position offset.
