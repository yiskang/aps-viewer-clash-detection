## Findings (not fixed, preserved for owner)
- **F-1 (suspected defect, Low/Medium): Manager and Editor disagree on readiness after `hideModel`.** With Structure hidden (`viewer.hideModel(2)`, same key), the Manager row of the active test 1 says `Audubon_Structure_clash_test is not loaded` / `Models changed since this run`, but the editor still reports `Ready to run`, `setup.models[...].ready=true, registered=true`, `canRun=true` (checked after a 6 s wait, in both views), and pressing Run completed with `2277 clashes`, coverage full, no banner (CT-30, CT-31, state-H H6/H7). Cause hypothesis from code reading: Manager readiness uses `registry.bindingFor(key)` (null for the hidden model) while the editor's `setup.models` uses the catalog `loaded`/`registered` flags that do not change on hide. Spec §26.6 says the editor's `validateSetup` stays the only Run gate, so the run succeeding may be spec-conformant; the disagreement is still a visible product contradiction. Minimal correction (owner decision required): either make the editor's per-model readiness consume the same binding fact, or word the Manager text as advisory only. No production edit was made.
- **O-1:** Model Browser root eye is node visibility, not model departure (no readiness change); there is no Viewer UI path for hide/unload of a model.
- **O-2:** Editor `vm.test.lastRun` is retained after Reset (see F).
- **O-3:** Viewer toolbar glyph font shows letters in the very first snapshot before load completes only (transient, not a Clash Panel issue).
